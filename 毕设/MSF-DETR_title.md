# 《密集笼养环境下基于多尺度注意力的死禽小目标检测算法研究》

英文题目：

**Research on Dead Poultry Small-Object Detection in Dense Cage-Farming

# 二、算法名称

**MSF-DETR**

全称：

**Multi-Scale Fine-grained DETR**

中文：

**多尺度细粒度 DETR 死禽小目标检测算法**

------------------------------------------------------------------------

# 三、研究背景

随着规模化、智能化养殖的发展，利用计算机视觉自动监测禽类健康状态具有实际应用价值。

在密集笼养环境中，死禽检测与普通鸡目标检测存在明显差异：

1.  死禽可能处于鸡群内部，目标区域较小；
2.  笼架、笼网和其他鸡体会造成遮挡；
3.  密集鸡群容易产生目标粘连；
4.  死禽与休眠、趴卧活禽在外观上具有较高相似性；
5.  不同光照和养殖环境会增加检测难度。

因此，本课题将研究重点放在：

> **密集笼养环境下的死禽小目标检测。**

------------------------------------------------------------------------

# 四、数据集问题与调整方案

目前自建死禽数据集规模较小，因此本课题不建议完全依赖单一小规模数据集训练
Transformer 检测模型。

经过资料检索，可以找到一些公开的禽类/死禽数据资源。

## 4.1 公开数据资源

### 资源 1：Poultry Detection for Counter

约 7,452 张图像，包含多个禽类相关类别，其中包括：

-   Chicken
-   Dead chicken
-   Healthy Broiler
-   lethargic chicken
-   Sick Chicken
-   Stressed chicken
-   等。

该数据集与本课题的死禽识别任务具有较高相关性，可作为辅助数据来源。

------------------------------------------------------------------------

### 资源 2：Poultry Dataset

约 7,454 张图像，包含 `Dead chicken` 等类别。

可以考虑用于：

-   辅助训练；
-   数据补充；
-   模型预训练；
-   外部测试。

------------------------------------------------------------------------

### 资源 3：Dead Chicken Detector

约 86 张图像，类别：

``` text
dead_bird
```

虽然规模较小，但任务与死禽检测高度相关，可以用于补充死禽样本。

------------------------------------------------------------------------

### 资源 4：PIO

PIO 是面向真实商业和实验养殖环境的肉鸡检测数据集。

公开资料显示：

-   1,487 张人工标注图像；
-   超过 327,289 个 broiler 实例；
-   单张图像最多约 500 只鸡；
-   包含高密度养殖环境；
-   包含不同生长阶段。

该数据集非常适合研究：

-   小目标；
-   密集目标；
-   鸡群遮挡；
-   复杂养殖环境。

但它主要是活鸡检测数据，因此不能直接替代死禽数据集。

------------------------------------------------------------------------

# 五、推荐的数据组织方式

本课题推荐采用：

> **"公开数据辅助训练 + 自建数据集核心训练/微调 + 独立测试集最终评价"**

而不是简单地把所有数据随机混合。

------------------------------------------------------------------------

## 5.1 辅助数据

用于让模型学习：

-   鸡体结构；
-   鸡体纹理；
-   鸡体姿态；
-   密集鸡群；
-   不同尺度鸡目标。

------------------------------------------------------------------------

## 5.2 核心数据

自己的死禽数据集仍然作为本课题核心数据。

最终模型必须在自己的目标场景上进行验证。

------------------------------------------------------------------------

## 5.3 测试数据

测试集必须尽可能独立。

尤其对于视频数据，不建议将同一视频的连续帧随机拆到 Train / Val / Test。

推荐：

``` text
视频 1 → Train
视频 2 → Validation
视频 3 → Test
```

而不是：

``` text
同一视频
   ↓
随机抽帧
   ├── Train
   ├── Val
   └── Test
```

这样可以减少数据泄漏造成的虚高结果。

------------------------------------------------------------------------

# 六、研究内容

本课题围绕 RT-DETRv2 开展三个主要改进。

## 6.1 高分辨率特征增强

针对死禽目标较小、局部暴露的问题，引入浅层高分辨率特征，探索 P2/P3
等特征层的使用方式。

主要目标：

-   保留小目标细节；
-   提高小目标定位能力；
-   降低小目标漏检。

主要评价：

-   AP_S；
-   Recall；
-   mAP。

------------------------------------------------------------------------

## 6.2 多尺度注意力机制

针对：

-   鸡群密集；
-   目标遮挡；
-   笼网干扰；
-   复杂背景；

设计轻量化多尺度注意力模块。

主要目标：

-   强化有效目标区域；
-   提高遮挡目标特征表达；
-   减少背景干扰。

主要评价：

-   mAP；
-   Precision；
-   Recall；
-   遮挡场景检测结果；
-   参数量；
-   FLOPs；
-   FPS。

------------------------------------------------------------------------

## 6.3 细粒度特征学习

针对：

> 死禽 vs 休眠/趴卧活禽

之间的视觉相似性，在训练阶段增加 SupCon。

主要目标：

-   提升目标特征的可分性；
-   减少相似类别误检；
-   提高 Precision。

部署阶段不保留 SupCon 分支。

------------------------------------------------------------------------

# 七、整体技术路线

``` text
公开禽类数据
      ↓
辅助训练
      ↓
自建死禽数据集
      ↓
RT-DETRv2 Baseline
      ↓
高分辨率特征增强
      ↓
多尺度注意力
      ↓
RT-DETRv2 Detection Head
      ↓
死禽检测
```

训练阶段：

``` text
                Feature
                   │
        ┌──────────┴──────────┐
        ↓                     ↓
  Detection Head        Projection Head
        ↓                     ↓
     L_det                  L_supcon
        └──────────┬──────────┘
                   ↓
             L = L_det + λL_supcon
```

# 九、对比实验

选择具有代表性的目标检测模型进行比较：

-   YOLOv8；
-   YOLOv11；
-   RT-DETRv2；
-   MSF-DETR。

所有模型尽可能使用：

-   相同数据集；
-   相同测试集；
-   相同输入尺寸；
-   相同评价指标；
-   尽可能一致的训练条件。

不预先假设某一种模型一定具有更高精度，最终以实验结果为依据。

# 十三、实现可行性控制

本课题不从零实现 DETR。

采用：

> **成熟 RT-DETRv2 开源实现 + 渐进式修改**

降低工程风险。

实际开发顺序：

``` text
第一阶段
RT-DETRv2 跑通
        ↓
第二阶段
自己的数据集训练 Baseline
        ↓
第三阶段
高分辨率特征
        ↓
第四阶段
多尺度注意力
        ↓
第五阶段
SupCon
        ↓
第六阶段
完整消融与对比
        ↓
第七阶段
部署
```

如果 P2 修改成本过高，可以调整为其他浅层高分辨率特征方案。

如果 SupCon 训练不稳定，应优先保证检测主干和前两个改进模块完成，再将
SupCon 作为后续实验模块。
