# 毕业设计题目与算法汇报

---

## 一、 毕业设计题目信息

* **中文题目**：《面向密集笼养环境下的异常禽只的小物体目标检测算法研究》
* **英文题目**：*Research on Dead Poultry Small-Object Detection in Dense Cage-Farming Environments Based on Multi-Scale Attention and Fine-Grained Feature Learning*
* **算法名称**：**MSF-DETR**（Multi-Scale Fine-grained DETR，多尺度细粒度 DETR 死禽小目标检测算法）
* **基线框架**：**RT-DETRv2**（实时 Transformer 目标检测器）

---

## 二、 核心创新点

本课题针对密集笼养场景下死禽检测的“小目标丢失、重度遮挡、死禽/休眠活禽外观极度相似”三大难题，提出以下三项核心创新点：

1. **浅层高分辨率特征增强（解决死禽小目标极易丢失问题）**
   * **原理**：死禽在笼养监视画面中占比极小，深层网络多次下采样易导致空间细节严重丢失。
   * **创新**：探索引入 $P_2 / P_3$ 浅层高分辨率特征图，补充丰富的边缘与纹理几何细节，极大提升死禽小目标的定位精度与召回率（$AP_S$）。

2. **轻量化多尺度注意力融合（解决密集鸡群与笼网重度遮挡问题）**
   * **原理**：笼网交叉、鸡体粘连及杂乱羽毛对死禽的显性特征形成重度遮挡与背景干扰。
   * **创新**：在多尺度特征融合层设计轻量化注意力模块，自适应计算通道与空间权重，强制网络聚焦于死禽被遮挡区域与关键判别部位，有效抑制无用背景噪声。

3. **训练期双分支细粒度对比学习（解决死禽与休眠/趴卧活禽视觉极度相似问题）**
   * **原理**：死禽与趴卧休眠活禽在姿态和外观上高度相似，传统分类损失难以拉开其细粒度特征差距，极易产生误检。
   * **创新**：在训练阶段引入辅助投影头与**监督对比学习损失（SupCon）**，在低维对比空间中显式拉大“死禽”与“休眠活禽”的特征距离；**推理阶段直接完全剔除辅助分支**，零成本保留高 FPS 实时推理性能。

## 三、 算法流程

### 3.1 算法整体架构与数据流

MSF-DETR 算法由**主干网络**、**高分辨率增强与注意力融合模块**、**Transformer 编解码器**以及**训练期双分支损失函数**构成。整体数据流图如下：

```
                             [ 输入笼养图像 X ]
                                     │
                          [ Backbone 骨干网络提取 ]
                                     │
               ┌─────────────────────┴─────────────────────┐
               ▼                                           ▼
      [ 浅层高分辨率特征 P2/P3 ]                   [ 深层语义特征 P4/P5 ]
               │                                           │
               └─────────────────────┬─────────────────────┘
                                     ▼
                      [ 轻量化多尺度注意力机制 ]
                       (增强遮挡特征，抑制背景噪声)
                                     │
                        [ 融合特征 Feature Fusion ]
                                     │
                          [ RT-DETRv2 Encoder ]
                                     │
                     [ Transformer Decoder + Queries ]
                                     │
                               [ 目标级特征 ]
                                     │
                   ┌─────────────────┴─────────────────┐
                   ▼                                   ▼
          [ 检测头 Detection Head ]           [ 投影头 Projection Head ]
                   │                               (仅训练阶段存在)
                   ▼                                   ▼
          [ 边框与类别预测 (L_det) ]                 [ SupCon 对比损失 (L_supcon) ]
                   │                                   │
                   └─────────────────┬─────────────────┘
                                     ▼
                         [ 总损失 L = L_det + λL_supcon ]
```

### 3.2 算法核心执行步骤（六步流程）

* **步骤 1：输入图像与多尺度特征提取 (Backbone Feature Extraction)**
  * 输入尺寸为 $H \times W \times 3$ 的密集笼养死禽图像，通过 Backbone（如 ResNet / HGNetv2）进行多阶下采样，提取多尺度特征图集合 $\{C_2, C_3, C_4, C_5\}$。
* **步骤 2：浅层高分辨率特征保留与增强 (High-Resolution Feature Enhancement)**
  * 保留并接入浅层高分辨率特征（如 $P_2 / P_3$ 级特征），保留死禽小目标的关键边缘与局部细节，防止小目标信息遗失。
* **步骤 3：多尺度注意力特征自适应融合 (Multi-Scale Attention Feature Fusion)**
  * 将增强后的多尺度特征输入轻量注意力模块，在通道与空间维度计算自适应注意力权重，自动聚焦死禽显性与被遮挡区域，削弱笼网及环境杂乱背景干扰。
* **步骤 4：Transformer 编解码与 Query 交互 (Encoder-Decoder & Query Interaction)**
  * 特征送入 Encoder 进行跨尺度信息交互；提取 Top-K 高置信度特征初始化 Object Queries；Decoder 通过 Cross-Attention 不断聚合死禽局部细节与全局上下文信息。
* **步骤 5：双分支损失计算与细粒度特征学习 (Training Loss Computation)**
  * **检测主分支 ($L_{det}$)**：检测头输出预测框与类别，计算分类损失（VFL）与回归损失（GIoU + L1）。
  * **对比辅助分支 ($L_{supcon}$)**：目标特征输入投影头，利用 SupCon 损失显式拉大死禽与休眠/趴卧活禽的特征距离，提高细粒度判别力。
  * **总训练损失**：$L = L_{det} + \lambda L_{supcon}$。
* **步骤 6：推理卸载与零延迟部署 (Inference & Deployment)**
  * 训练完成后，**直接移除投影头与 SupCon 损失分支**，推理阶段仅保留主干检测通路，纯粹依靠强判别力特征快速预测，**完全不增加推理阶段计算量与延迟（保持高 FPS）**。

## 四、 毕设算法的具体实现路线

1. **阶段 1（Baseline 跑通）**：基于开源 RT-DETRv2，使用死禽数据集跑通基线模型，记录 Precision、Recall、$mAP_{50}$、Params、FLOPs 及 FPS。
2. **阶段 2（高分辨率模块）**：接入 $P_2 / P_3$ 浅层高分辨率特征，测试小目标检测指标 $AP_S$ 的提升情况。
3. **阶段 3（多尺度注意力）**：在特征融合层接入轻量注意力机制，针对不同遮挡等级（无遮挡/轻度/重度）进行对比测试。
4. **阶段 4（SupCon 细粒度学习）**：训练期加入 SupCon 辅助分支，利用 t-SNE 验证死禽与趴卧活禽的特征分离度，降低误检率。
5. **阶段 5（消融与对比实验）**：完成逐级消融实验，并与 YOLOv8、YOLOv11 等代表性算法进行性能对比。
