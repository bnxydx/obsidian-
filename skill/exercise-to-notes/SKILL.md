# Exercise to Notes — 教材习题反哺笔记

从用户指定的教材 PDF 中提取习题页+答案页，逐题分析考点，生成双格式解析文档，再对比目标笔记文件补充缺失内容。

## 触发条件

用户说类似以下内容时加载本 skill：
- "把这几页的题总结一下，补充到笔记里"
- "提取 PDF 第 X~Y 页习题，知识点写进 XXX.md"
- "找题 -> 解析 -> 补笔记"
- 或给出 PDF 路径 + 页码 + 目标笔记路径的完整需求

## 输入要求

用户需提供：
- **PDF 路径**：教材的绝对路径
- **习题页码**：如 205~208
- **目标笔记路径**：要补充的 .md 笔记路径（如 `4.4路由算法与路由协议.md`）

可选提供答案页页码；若不提供，file-agent 会自动扩大搜索范围找到答案页。

## 执行流程

### 阶段一：生成题目解析文档（派发 file-agent）

把以下任务**一次性派发**给 file-agent：

> 从 PDF 的习题页+答案页提取全部题目，在笔记目录下生成一个解析文件（文件名自拟，需与章节主题相关），内容分两部分：
>
> **第一部分「逐题考点」**：按题号列出每题的题干核心、正确选项、四个选项逐一解析（正确选项为何对、错误选项为何错）。每道题不能遗漏任何一个选项。
>
> **第二部分「分知识点归类」**：按知识模块归类（路由基础/RIP/OSPF/BGP/对比/计算/易错点等），每个知识点下标注对应题号，末尾附全量题号覆盖清单确认无遗漏。

- global_goal 填入用户原始完整需求
- current_task 填入上述任务描述 + 附件（PDF路径等）
- 必须使用 `inherit_agent_id` 继承历史 file-agent（如有），避免重复传 PDF

产出物示例：
```
```<yyb-product>
[XXX-习题知识点.md](<笔记目录/XXX-习题知识点.md>)
```
```

### 阶段二：笔记反哺（派发 file-agent，继承上一轮 file-agent）

再次派发 file-agent，要求：

1. 先读取目标笔记，与阶段一的解析文档交叉对比，找出**笔记中缺失但被习题考察的知识点**
2. 在笔记对应位置**只追加、不删除原文**，按位置插入缺失内容
3. 每个新增内容块第一行加 `(新补充)` 标记

典型追加项目：
- 缺失的对比表格/定义（如静态vs动态路由、路由收敛等）
- 缺失的协议机制细节（如 Hello 分组、四类路由器、区域划分首要目的等）
- 多协议对比速记表（算法类型、封装协议、TCP/IP 层次）
- 计算题型方法论（公式 + 示例）
- 高频易错点速查表

约束：原文一字不动，只补缺不重复已有内容，保持与原文一致的术语和简洁风格。

### 阶段三：呈现结果

将两个阶段的结果汇总，输出最终的 yyb-product 卡片。

## 关键约束

1. **两次派发必须继承**：阶段二派发的 `inherit_agent_id` 必须为阶段一的 `sa-xxx`，确保 file-agent 持有 PDF 上下文和已生成的解析文档内容
2. **逐一解析不遗漏**：每道题的每个选项都必须分析正确/错误原因
3. **新增标注**：笔记中每个新增内容块前必有 `(新补充)`
4. **只追加不删除**：绝不修改或删除笔记原有内容

## 示例

用户输入：
> C:\D\baiduwangpan\2026计算机网络.pdf 第205~208页习题，总结知识点补充到 C:\D\obsidian笔记\408\计网\第四章网络层\4.4路由算法与路由协议.md

执行：
1. 派发 file-agent 提取 P205~208 + 答案页，生成 `IPv6与路由协议-4.4节习题知识点.md`
2. 派发 file-agent（继承上一步）读取笔记与解析文档交叉对比，在笔记中追加：静态vs动态路由对比表、路由收敛定义、OSPF Hello分组/四类路由器、三协议对比速记、计算题型方法论、高频易错点速查表
3. 输出最终 yyb-product 卡片
