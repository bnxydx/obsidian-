### Transbot 人脸追踪与 WSL 远程显示完整操作备忘

#### 1. 硬件与环境准备（前置检查）

Bash

```
# 确认摄像头设备号（确认是 /dev/video0 还是 /dev/video1）
ls /dev/video*

# 若端口被旧进程占用，清理设备占用与残留进程
killall -9 python python3 2>/dev/null
sudo fuser -k /dev/video1 2>/dev/null

# 若存在僵尸节点报错，清理 ROS Master 节点注册表
rosnode cleanup
```

#### 2. 代码适配与检查（若设备号或节点重名需改动）

Bash

```
# 将代码中的摄像头索引修改为 /dev/video1（根据实际设备号设定）
sed -i 's/cv2.VideoCapture(0)/cv2.VideoCapture(1)/g' ~/transbot_ws/src/transbot_facetracker/face_follow.py

# 防止多人调试或多次启动时被踢出（开启匿名节点）
sed -i 's/rospy.init_node("faceTracker")/rospy.init_node("faceTracker", anonymous=True)/g' ~/transbot_ws/src/transbot_facetracker/face_follow.py
```

#### 3. 运行控制（分两个 WSL 终端执行）

##### 终端 1：启动机器人底层硬件服务

在 WSL 终端中登录小车并启动底盘与舵机驱动，**保持该终端前台运行，不可关闭**：

  

Bash

```
ssh pi@192.168.31.32
roslaunch transbot_bringup bringup.launch
```

> **启动成功标志**：终端显示 `Serial Opened! Baudrate=115200`、`Gyro calibration complete!` 且持续挂起。
> 
>   

##### 终端 2：开启 X11 转发并运行人脸追踪

新建第二个 WSL 终端，添加 `-Y` 参数登录以将图形窗口回传至 Windows 桌面：

  

Bash

```
ssh -Y pi@192.168.31.32
rosrun transbot_facetracker face_follow.py
```

> **启动成功标志**：终端持续打印 `('capture get FPS : ', 30.x)`，Windows 桌面上弹出 OpenCV 实时检测窗口。

#### 4. 故障排查与调试命令

|**调试场景**|**命令**|**说明**|
|---|---|---|
|**测试舵机硬件响应**|`rostopic pub -1 /PWMServo transbot_msgs/PWMServo "{id: 1, angle: 90}"`|手动给 1 号云台舵机发送角度指令，验证电机与供电是否正常|
|**监听追踪指令输出**|`rostopic echo /PWMServo`|移动人脸，观察是否有实时角度数据刷新|
|**在线调节 PID 参数**|`rosrun rqt_reconfigure rqt_reconfigure`|打开调参 GUI，调整 `faceTracker` 的 `Kp1` / `Kp2` 参数（推荐初始值 `0.02` ~ `0.05`）|
|**查看图像话题列表**|`rostopic list \| grep -E 'image\|camera'`|排查当前是否有相机数据话题处于发布状态|
