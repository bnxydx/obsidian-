# ROS 1 Noetic 安装与海龟测试

## 一、环境确认

当前环境：

- Ubuntu 20.04.6 LTS
    
- ROS 1 Noetic
    
- WSL
    
- Windows 11
    

查看 Ubuntu 版本：

```bash
lsb_release -a
```

确认输出：

```text
Description: Ubuntu 20.04.6 LTS
Release:      20.04
Codename:     focal
```

---

# 二、更新 Ubuntu 软件源

```bash
sudo apt update
sudo apt upgrade -y
```

安装 ROS 需要的基础工具：

```bash
sudo apt install curl gnupg2 lsb-release -y
```

---

# 三、添加 ROS 1 软件源

## 1. 创建密钥目录

```bash
sudo mkdir -p /etc/apt/keyrings
```

## 2. 下载 ROS 软件源密钥

```bash
sudo curl -fsSL https://raw.githubusercontent.com/ros/rosdistro/master/ros.key \
  -o /etc/apt/keyrings/ros-archive-keyring.gpg
```

## 3. 添加 ROS Noetic 软件源

Ubuntu 20.04 对应 ROS Noetic，所以使用 `focal`：

```bash
echo "deb [arch=$(dpkg --print-architecture) signed-by=/etc/apt/keyrings/ros-archive-keyring.gpg] http://packages.ros.org/ros/ubuntu focal main" | sudo tee /etc/apt/sources.list.d/ros1.list
```

## 4. 更新软件源

```bash
sudo apt update
```

如果看到类似：

```text
Get:5 http://packages.ros.org/ros/ubuntu focal InRelease
Get:6 http://packages.ros.org/ros/ubuntu focal/main amd64 Packages
```

说明 ROS 软件源配置成功。

---

# 四、安装 ROS 1 Noetic

安装完整桌面版：

```bash
sudo apt install ros-noetic-desktop-full -y
```

这个版本包含：

- ROS 核心
    
- RViz
    
- turtlesim
    
- 常用 ROS 工具
    
- 常用 ROS 功能包
    

### 注意

安装过程中如果出现：

```text
Failed to fetch
Connection timed out
```

不一定是安装失败，通常是网络下载超时。

可以直接重新执行：

```bash
sudo apt install ros-noetic-desktop-full -y
```

APT 会继续下载没有成功的部分，不需要重新下载已经安装成功的软件包。

---

# 五、配置 ROS 环境变量

将 ROS Noetic 添加到 `.bashrc`：

```bash
echo "source /opt/ros/noetic/setup.bash" >> ~/.bashrc
```

立即加载：

```bash
source ~/.bashrc
```

检查 ROS 版本：

```bash
rosversion -d
```

应该得到：

```text
noetic
```

检查 `roscore`：

```bash
which roscore
```

应该得到：

```text
/opt/ros/noetic/bin/roscore
```

---

# 六、启动 ROS Master

ROS 1 的核心是 ROS Master。

打开**第一个 WSL 终端**：

```bash
roscore
```

正常情况下会看到：

```text
started core service [/rosout]
```

并且：

```text
ROS_MASTER_URI=http://DESKTOP-Q20A2OI:11311/
```

说明 ROS Master 已经启动。

### 注意

这个终端需要一直保持运行，**不要关闭**。

---

# 七、检查 ROS Master

打开**第二个 WSL 终端**。

加载 ROS 环境：

```bash
source /opt/ros/noetic/setup.bash
```

查看 ROS Master：

```bash
echo $ROS_MASTER_URI
```

正常情况下：

```text
http://localhost:11311
```

查看 11311 端口：

```bash
ss -lntp | grep 11311
```

如果看到：

```text
LISTEN ... 0.0.0.0:11311 ...
```

说明 ROS Master 正在监听 11311 端口。

---

# 八、测试 ROS 节点

查看当前 ROS 节点：

```bash
rosnode list
```

刚启动 ROS Master 时应该看到：

```text
/rosout
```

查看当前 ROS Topic：

```bash
rostopic list
```

应该看到：

```text
/rosout
/rosout_agg
```

这说明：

```text
ROS Master
    ↓
rosnode
    ↓
rostopic
```

基本通信已经正常。

---

# 九、启动海龟 turtlesim

保持第一个终端的 `roscore` 不动。

打开**第二个终端**：

```bash
source /opt/ros/noetic/setup.bash
```

启动海龟：

```bash
rosrun turtlesim turtlesim_node
```

正常情况下会弹出：

```text
Turtlesim
```

并看到一只小乌龟。

---

# 十、检查海龟节点

再打开**第三个终端**：

```bash
source /opt/ros/noetic/setup.bash
```

查看节点：

```bash
rosnode list
```

此时应该看到：

```text
/rosout
/turtlesim
```

说明 turtlesim 已经作为一个 ROS Node 运行。

查看 Topic：

```bash
rostopic list
```

应该可以看到类似：

```text
/rosout
/rosout_agg
/turtle1/cmd_vel
/turtle1/color_sensor
/turtle1/pose
```

其中：

```text
/turtle1/cmd_vel
```

用于控制海龟运动。

```text
/turtle1/pose
```

用于获取海龟的位置和姿态。

---

# 十一、使用键盘控制海龟

打开**第四个终端**：

```bash
source /opt/ros/noetic/setup.bash
```

运行：

```bash
rosrun turtlesim turtle_teleop_key
```

然后使用键盘方向键：

```text
↑  前进

↓  后退

←  左转

→  右转
```

如果海龟能够随着键盘移动，说明：

```text
键盘节点
   ↓
/turtle1/cmd_vel
   ↓
/turtlesim
   ↓
海龟运动
```

整个 ROS 1 Topic 通信链路已经测试成功。

# 十三、ROS 1 三个最重要的概念

刚刚的海龟实验实际上已经涉及 ROS 1 最核心的通信机制：

### 1. Node（节点）

一个执行具体任务的程序。

例如：

```text
/turtlesim
/turtle_teleop_key
/rosout
```

### 2. Topic（话题）

节点之间传递数据的通道。

例如：

```text
/turtle1/cmd_vel
/turtle1/pose
```

### 3. ROS Master

负责帮助 ROS 节点相互发现。

默认端口：

```text
11311
```

因此海龟实验本质上就是：

```text
turtle_teleop_key
       │
       │ 发布速度指令
       ↓
/turtle1/cmd_vel
       │
       ↓
   /turtlesim
       │
       │ 发布位置
       ↓
/turtle1/pose
```

这就是 ROS 1 中非常典型的 **Publisher → Topic → Subscriber** 通信模型。
