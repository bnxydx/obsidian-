## 摘  要

在智能机器人应用中，利用单目视觉传感器实现对环境特征的感知并联动执行机构完成自主作业，是机器人技术的核心基础。本课程设计针对实验室环境，基于Transbot智能移动机器人平台，设计并实现了一套具备色彩视觉引导行驶与白色目标物体自主水平平伸抓取功能的机器人系统。

系统以树莓派4B为主控制器，通过USB单目广角摄像头实时采集前方场景画面，利用OpenCV图像处理库构建色彩识别算法。系统的核心控制规则为：当摄像头识别到绿色信号时，驱动底盘直线前进；当识别到红色信号或视野内未检测到绿色时，底盘立即制动停止，保持不动；当正面视野检测到白色物体目标时，小车立即停车，联动3自由度机械臂执行水平向前平伸、夹爪抓取夹紧、蜂鸣器鸣笛提示并将物体抬起收拢至车身的完整抓取动作。针对实验初期手机屏幕UI按键多颜色干扰的问题，设计了主导色竞态裁决机制，有效保证了动作判决的唯一性与稳定性。

在真实硬件环境下的联调测试表明，系统运行流畅，对绿、红、白三种颜色的识别准确率高，底盘启停响应灵敏，机械臂能够平稳完成向前平伸抓取并收回，满足了课程设计的全部功能指标。

**关键词**：单目视觉；色彩识别；移动机器人；机械臂平伸抓取；OpenCV

## Abstract

In mobile robotics, employing monocular vision to perceive environmental features and trigger coordinated robotic actions is a fundamental technical capability. In this course design, an intelligent robot system featuring color-guided movement and autonomous horizontal grasping is designed and implemented on the Transbot robot platform in a laboratory environment.

The system utilizes a Raspberry Pi 4B as the primary processor. A monocular USB camera captures video streams in real-time, which are processed using the OpenCV computer vision library. The core operational rules are defined as follows: when a green signal is detected, the mobile chassis moves forward; when a red signal or absence of green is detected, the chassis stops immediately and remains stationary; when a white object is identified in front of the vehicle, the car stops immediately and triggers a 3-DOF robotic arm to horizontally reach out, clamp the target object, sound the buzzer, and lift the object back onto the vehicle body. To solve the color interference caused by UI buttons on smartphone screens, a dominant color arbitration mechanism is implemented to ensure robust and exclusive decision-making.

Real-world hardware experiments demonstrate that the system operates stably. The color recognition for green, red, and white targets is accurate, chassis braking is prompt, and the robotic arm reliably performs horizontal grasping, fulfilling all requirements of the comprehensive practical training.

**Keywords**: Monocular Vision; Color Recognition; Mobile Robot; Horizontal Arm Grasping; OpenCV

# 第1章 系统概述与结构组成

## 1.1 系统设计目标与实现功能

本次课程设计的任务是基于单目视觉传感器，设计并实现一套具备视觉色彩感知与目标抓取功能的移动机器人系统。根据实际实验调试与现场验证，系统完整实现的核心功能如下：
1. **绿灯前进行驶**：单目摄像头检测到前方视野出现绿色视觉信号时，小车底盘电机启动，并保持直线前进；
2. **红灯或未识别信号时静止**：当摄像头识别到红色信号，或者视野内没有检测到绿色信号时，小车立即刹停，保持原地不动；
3. **白色物体检测与水平平伸抓取**：当小车在行进或静止中检测到正前方出现白色物品时，小车立即停车，机械臂从车身后方收拢姿态向前水平平伸出爪，夹紧白色物品，蜂鸣器鸣叫两声提示，随后将物品抬起收回车身；
4. **Web端实时图像监视与手机信号发射**：小车建立网页服务（8090端口），电脑端可查看实时摄像头视频与检测框，手机端可打开专属信号页面，点击屏幕任意切换红、绿、白色，作为测试靶标。

## 1.2 硬件系统构成

系统以Transbot智能小车为基础硬件平台，整体硬件由五部分组成：
1. **主控板**：树莓派4B（Raspberry Pi 4B），搭载Ubuntu 18.04系统，负责运行Python 3、OpenCV视觉处理程序及Flask网页服务器；
2. **单目摄像头**：USB免驱广角摄像头，安装于小车前部云台上，负责采集前方RGB彩色图像；
3. **机器人底盘**：履带式底盘，由STM32扩展板控制左右两个直流减速电机驱动；
4. **3自由度机械臂与夹爪**：包含7号大臂舵机、8号小臂舵机和9号夹爪舵机，通过串口总线由底板驱动；
5. **供电系统**：11.1V锂电池组，为主控板和电机舵机提供稳定电源。

# 第2章 核心功能设计与实现原理

## 2.1 单目摄像头视频采集与流媒体推流

系统使用OpenCV的`cv2.VideoCapture`打开摄像头设备。为保证图像传输的低延迟与高流畅度，程序显式配置摄像头以硬件MJPEG格式输出（分辨率640×480，帧率30 FPS），并将驱动的缓冲区深度限制为1（`CAP_PROP_BUFFERSIZE = 1`）。这样可彻底消除多帧缓冲带来的图像滞后，确保小车每次处理的都是眼前最新的实时图像。

采集到的图像经过算法处理并在画面顶部绘制HUD状态信息后，通过Flask以多部分内容流（Multipart/x-mixed-replace）的形式向浏览器推送，用户在局域网内任意设备的浏览器访问 `http://192.168.31.32:8090` 即可实时查看监控画面。

## 2.2 视觉色彩识别与小车运动控制原理

小车的运动控制逻辑完全取决于摄像头前方的视觉识别结果：
1. **色彩空间转换**：RGB色彩对光照强弱变化敏感，因此算法首先将图像转为HSV色彩空间（Hue色调、Saturation饱和度、Value明度），在HSV空间中分别设定绿、红、白三色的取值区间进行掩模二值化；
2. **绿色前进逻辑**：当画面中检测到的绿色区域面积超过设定门限（800像素）时，系统判定为绿色信号有效，调用底盘控制函数 `bot.set_car_motion(0.18, 0)` 驱动小车以 0.18 m/s 的平稳速度向前行驶；
3. **红色刹车逻辑**：当画面中检测到红色区域时，系统判定为红色停车信号，立即调用 `bot.set_car_motion(0, 0)` 强制刹停；
4. **其他情况静止逻辑**：若视野中既没有红色也没有绿色，或者绿色信号移出视线，系统默认保持静止（`bot.set_car_motion(0, 0)`），防止小车无信号时乱跑失控；
5. **0.4秒平滑保持滤波**：为避免小车行驶时由于地面轻微颠簸导致个别单帧漏检绿灯而频繁卡顿，程序加入了0.4秒的时间平滑保持机制，若绿灯短暂丢失不超过0.4秒，仍维持前行，超过0.4秒才完全刹停。

## 2.3 白色目标识别与机械臂水平平伸抓取原理

白色物品抓取是系统的关键交互功能：
1. **白色特征提取**：白色在HSV中表现为极低的饱和度（$S < 45$）和很高的明度（$V > 175$），同时在RGB中R、G、B三个分量数值均较大且非常接近。程序结合HSV与RGB双重约束，精准识别前方白色目标并剔除顶部日光灯反光；
2. **水平平伸抓取姿态设计**：传统机械臂常采用向下低头弯腰抓取的姿势，但在实测中发现机械臂低头会完全挡住摄像头的视野。因此本设计将动作重构成“水平向前平伸抓取”：
   - **初始待机**：大臂7号舵机220°后仰收拢，小臂8号舵机30°贴身，夹爪9号舵机40°张开（完全移出摄像头前视场）；
   - **水平平伸**：小车刹停后，大臂降至160°前倾，小臂伸展至150°呈水平向前状态，夹爪保持张开（40°）；
   - **闭合夹紧**：夹爪舵机闭合至175°，紧紧夹住白色目标；
   - **蜂鸣鸣笛**：调用下位机蜂鸣器响两声，提示抓取成功；
   - **抬起收回**：大臂重新抬起至210°，小臂折叠回50°，夹爪保持夹紧（175°），将物品稳妥带回车身上方。

## 2.4 解决按键杂色干扰的主导色裁决原理

在早期测试中，当我们使用手机作为信号发射器时，手机屏幕下方难免会有彩色按钮或者系统白色栏，导致摄像头画面里同时出现了绿块、红块和白块，造成系统误判混乱。

为解决这一问题，我们采取了“主导色竞态裁决”方案：
1. 算法计算各颜色最大连通块的面积，只有面积最大且占据绝对主导地位的颜色才生效；
2. 设定优先级：白色抓取目标面积足够大时优先触发；红色停车优先级高于绿色；
3. 手机端发射屏优化：在手机网页（/signal）上去除了原先彩色的按钮底色，采用深黑灰色工具栏，并支持点击屏幕任意位置全屏切换纯色（🟢绿 ➔ 🔴红 ➔ ⚪白 ➔ ⚫黑），彻底杜绝了杂色外溢问题。

# 第3章 关键功能模块与对应代码实现

## 3.1 色彩检测模块 (color_detector.py) 代码实现与分析

色彩检测模块封装在 `ColorDetector` 类中，主要代码如下：

```python
class ColorDetector:
    def __init__(self):
        # 绿色 HSV 范围 (放宽饱和度下限以适应高亮度手机屏幕)
        self.lower_green = np.array([30, 35, 50])
        self.upper_green = np.array([92, 255, 255])
        
        # 红色 HSV 范围 (跨越 0 度分界线，两段合并)
        self.lower_red1 = np.array([0, 70, 60]); self.upper_red1 = np.array([12, 255, 255])
        self.lower_red2 = np.array([168, 70, 60]); self.upper_red2 = np.array([180, 255, 255])
        
        self.min_signal_area = 800    # 信号灯有效面积门限
        self.min_white_area = 1500    # 白色物体抓取面积门限
        self.kernel = cv2.getStructuringElement(cv2.MORPH_RECT, (5, 5))

    def detect(self, frame):
        h, w = frame.shape[:2]
        hsv = cv2.cvtColor(frame, cv2.COLOR_BGR2HSV)
        b, g, r = cv2.split(frame)
        
        # 1. 提取绿色掩模 (结合RGB防止强光发白漏检)
        mask_g_hsv = cv2.inRange(hsv, self.lower_green, self.upper_green)
        mask_g_rgb = ((g > r + 15) & (g > b - 20)).astype(np.uint8) * 255
        mask_g = cv2.morphologyEx(cv2.bitwise_and(mask_g_hsv, mask_g_rgb), cv2.MORPH_OPEN, self.kernel)
        
        # 2. 提取红色掩模
        mask_r = cv2.bitwise_or(cv2.inRange(hsv, self.lower_red1, self.upper_red1),
                                cv2.inRange(hsv, self.lower_red2, self.upper_red2))
        mask_r = cv2.morphologyEx(mask_r, cv2.MORPH_OPEN, self.kernel)
        
        # 3. 提取白色掩模 (低饱和度、高亮度，且屏蔽顶部15%日光灯区域)
        mask_w_hsv = cv2.inRange(hsv, np.array([0, 0, 175]), np.array([180, 45, 255]))
        rgb_diff = (np.maximum(np.maximum(r, g), b) - np.minimum(np.minimum(r, g), b))
        mask_w_rgb = ((r > 165) & (g > 165) & (b > 165) & (rgb_diff < 28)).astype(np.uint8) * 255
        mask_w = cv2.bitwise_and(mask_w_hsv, mask_w_rgb)
        mask_w[:int(h * 0.15), :] = 0  # 屏蔽天花板日光灯
        mask_w = cv2.morphologyEx(mask_w, cv2.MORPH_OPEN, self.kernel)

        # 计算连通域最大面积
        area_g = int(cv2.contourArea(max(get_contours(mask_g), key=cv2.contourArea))) if get_contours(mask_g) else 0
        area_r = int(cv2.contourArea(max(get_contours(mask_r), key=cv2.contourArea))) if get_contours(mask_r) else 0
        area_w = int(cv2.contourArea(max(get_contours(mask_w), key=cv2.contourArea))) if get_contours(mask_w) else 0
        
        # 主导色裁决
        sig = 'NONE'
        if area_w >= self.min_white_area and area_w > area_g and area_w > area_r:
            sig = 'WHITE'
        elif area_r >= self.min_signal_area and area_r > area_g:
            sig = 'RED'
        elif area_g >= self.min_signal_area:
            sig = 'GREEN'
            
        return sig, {'green_area': area_g, 'red_area': area_r, 'white_area': area_w}, frame
```

**代码解析**：
1. 在绿色掩模提取中，加入了 `(g > r + 15)` 的RGB约束，这是由于手机屏幕在调到最亮时中心会泛白，单纯HSV容易漏检，结合RGB通道差分能稳定锁住绿色；
2. 白色掩模增加了 `mask_w[:int(h * 0.15), :] = 0`，主动将画面顶部15%切除，避免天花板上的白炽日光灯被误识别为抓取目标；
3. 裁决部分使用多重条件比较，白色满足面积且大于红绿时确认抓取，红色大于绿色时优先刹车，只有绿色纯净超标时才输出GREEN。

## 3.2 自动运行决策控制循环实现与分析

在 `delivery_app.py` 中，`AutoSystem._loop` 函数在后台以 20Hz 频率持续监控视觉结果并下发小车控制指令：

```python
def _loop(self):
    while True:
        time.sleep(0.05)  # 20Hz 刷新周期
        if not self.auto_mode or self.is_grabbing:
            continue

        sig = self.last_detected_signal
        now = time.time()
        
        # 规则 1: 发现白色物体 -> 停车并执行平伸抓取
        if sig == 'WHITE':
            self.last_green_time = 0.0
            if (now - self.last_grab_time) > self.grab_cooldown:
                self.trigger_grab()
            else:
                self.robot.stop()
                self.state = 'WAITING'
                
        # 规则 2: 发现红色信号 -> 立即刹停
        elif sig == 'RED':
            self.last_green_time = 0.0
            self.robot.stop()
            self.state = 'STOPPED'
            
        # 规则 3: 识别到绿色 -> 驱动前进 (带0.4秒防抖保持)
        elif sig == 'GREEN' or (now - self.last_green_time < 0.4):
            if sig == 'GREEN':
                self.last_green_time = now
            self.robot.drive(self.speed, 0.0)  # 速度 0.18 m/s 直行
            self.state = 'MOVING'
            
        # 规则 4: 其他情况 (无绿色信号) -> 停车保持不动
        else:
            self.robot.stop()
            self.state = 'WAITING'
```

**代码解析**：
1. 通过判断 `self.is_grabbing` 保证机械臂在抓取过程中底盘绝对锁死不动，避免小车带动物体晃动；
2. 当 `sig == 'GREEN'` 时更新 `last_green_time`，若下一次循环短暂漏检，通过 `(now - self.last_green_time < 0.4)` 实现滤波平滑前行，消除颠簸顿挫；
3. `else` 分支直接调用 `self.robot.stop()`，严格保证没有绿灯时小车绝不自行移动。

## 3.3 机械臂水平平伸抓取动作序列代码实现与分析

机械臂水平抓取过程在独立工作线程中异步执行，确保耗时不阻塞视频流推流：

```python
def _grab_worker(self):
    self.is_grabbing = True
    self.state = 'GRABBING'
    self.last_green_time = 0.0
    self.robot.stop()  # 第一步: 必须刹停小车
    print("[ACTION] White object detected! Initiating horizontal grab sequence...")
    
    try:
        # 1. 机械臂水平向前平伸 (大臂160°, 小臂150°, 保持夹爪40°张开)
        self.robot.set_arm(j7=160, j8=150, j9=40, runtime=1200)
        time.sleep(1.4)
        
        # 2. 夹爪完全闭合夹紧白色物品 (舵机角度 175°)
        self.robot.set_arm(j9=175, runtime=700)
        time.sleep(0.9)
        
        # 3. 蜂鸣器提示抓取成功 (哔哔两声)
        self.robot.beep(120); time.sleep(0.15)
        self.robot.beep(120); time.sleep(0.4)
        
        # 4. 向上抬起并收拢折叠回车身 (大臂210°, 小臂50°, 夹爪保持175°紧夹)
        self.robot.set_arm(j7=210, j8=50, j9=175, runtime=1200)
        time.sleep(1.4)
        
        print("[ACTION] Horizontal grab completed successfully!")
        self.last_grab_time = time.time()
    except Exception as e:
        print("[ACTION] Error during grab:", e)
    finally:
        self.is_grabbing = False
        self.state = 'WAITING'
```

**代码解析**：
1. 动作执行严格分步，每步之间通过 `time.sleep` 等待舵机转动到位；
2. 第一阶段设置 Joint 7 = 160°、Joint 8 = 150°，使机械臂向前水平伸出，高度刚好正对前方放置的物品；
3. 夹紧后，第四阶段大臂抬高到 210°，小臂折叠为 50°，将物品牢固收抱在车体上方，重心稳妥。

## 4.4 干扰解决测试与效果分析

在本次实验过程中，针对真实测试遇到的问题进行了两项关键调试改进并得到了验证：
1. **解决手机按键颜色干扰**：最初手机界面底部有不同颜色的按钮，小车会同时看到绿、红、白而出现抽搐。通过在代码中加入“主导色竞态裁决”并将手机发射屏底栏按钮改为中性暗黑底色后，多色并存时系统只响应面积最大的主导色，彻底消除了冲突；
2. **解决机械臂遮挡视线**：将机械臂原本的低头下探姿势修改为水平平伸姿势，机械臂在出击和收回过程中均不挡住摄像头的正面视线，避免了抓取时画面剧烈晃动引起视觉失效的问题。

```python
# -*- coding: utf-8 -*-
import cv2
import numpy as np

def get_contours(mask):
    res = cv2.findContours(mask, cv2.RETR_EXTERNAL, cv2.CHAIN_APPROX_SIMPLE)
    return res[0] if len(res) == 2 else res[1]

class ColorDetector:
    def __init__(self):
        # 绿色 HSV 范围
        self.lower_green = np.array([30, 35, 50])
        self.upper_green = np.array([92, 255, 255])
        
        # 红色 HSV 范围 (跨越 0 度环)
        self.lower_red1 = np.array([0, 70, 60]); self.upper_red1 = np.array([12, 255, 255])
        self.lower_red2 = np.array([168, 70, 60]); self.upper_red2 = np.array([180, 255, 255])
        
        self.min_signal_area = 800
        self.min_white_area = 1500
        self.kernel = cv2.getStructuringElement(cv2.MORPH_RECT, (5, 5))

    def detect(self, frame):
        if frame is None or frame.size == 0:
            return 'NONE', {}, frame

        h, w = frame.shape[:2]
        hsv = cv2.cvtColor(frame, cv2.COLOR_BGR2HSV)
        b, g, r = cv2.split(frame)
        
        # 1. 绿色掩模
        mask_g_hsv = cv2.inRange(hsv, self.lower_green, self.upper_green)
        mask_g_rgb = ((g > r + 15) & (g > b - 20)).astype(np.uint8) * 255
        mask_g = cv2.bitwise_and(mask_g_hsv, mask_g_rgb)
        mask_g = cv2.morphologyEx(mask_g, cv2.MORPH_OPEN, self.kernel)
        
        # 2. 红色掩模
        mask_r = cv2.bitwise_or(cv2.inRange(hsv, self.lower_red1, self.upper_red1),
                                cv2.inRange(hsv, self.lower_red2, self.upper_red2))
        mask_r = cv2.morphologyEx(mask_r, cv2.MORPH_OPEN, self.kernel)
        
        # 3. 白色掩模 (低饱和度、高亮度，屏蔽天花板顶部15%)
        mask_w_hsv = cv2.inRange(hsv, np.array([0, 0, 175]), np.array([180, 45, 255]))
        rgb_diff = (np.maximum(np.maximum(r, g), b) - np.minimum(np.minimum(r, g), b))
        mask_w_rgb = ((r > 165) & (g > 165) & (b > 165) & (rgb_diff < 28)).astype(np.uint8) * 255
        mask_w = cv2.bitwise_and(mask_w_hsv, mask_w_rgb)
        mask_w[:int(h * 0.15), :] = 0
        mask_w = cv2.morphologyEx(mask_w, cv2.MORPH_OPEN, self.kernel)
        
        cnts_g = get_contours(mask_g)
        cnts_r = get_contours(mask_r)
        cnts_w = get_contours(mask_w)
        
        area_g = int(cv2.contourArea(max(cnts_g, key=cv2.contourArea))) if cnts_g else 0
        area_r = int(cv2.contourArea(max(cnts_r, key=cv2.contourArea))) if cnts_r else 0
        area_w = int(cv2.contourArea(max(cnts_w, key=cv2.contourArea))) if cnts_w else 0
        
        annotated = frame.copy()
        sig = 'NONE'
        info = {'green_area': area_g, 'red_area': area_r, 'white_area': area_w}
        
        # 主导色竞态裁决
        if area_w >= self.min_white_area and area_w > area_g and area_w > area_r:
            sig = 'WHITE'
            x, y, bw, bh = cv2.boundingRect(max(cnts_w, key=cv2.contourArea))
            cv2.rectangle(annotated, (x, y), (x + bw, y + bh), (255, 255, 255), 3)
            cv2.putText(annotated, f"TARGET WHITE ({area_w}px)", (x, max(25, y - 10)),
                        cv2.FONT_HERSHEY_SIMPLEX, 0.75, (255, 255, 255), 2)
        elif area_r >= self.min_signal_area and area_r > area_g:
            sig = 'RED'
            x, y, bw, bh = cv2.boundingRect(max(cnts_r, key=cv2.contourArea))
            cv2.rectangle(annotated, (x, y), (x + bw, y + bh), (0, 0, 255), 3)
            cv2.putText(annotated, f"STOP RED ({area_r}px)", (x, max(25, y - 10)),
                        cv2.FONT_HERSHEY_SIMPLEX, 0.75, (0, 0, 255), 2)
        elif area_g >= self.min_signal_area:
            sig = 'GREEN'
            x, y, bw, bh = cv2.boundingRect(max(cnts_g, key=cv2.contourArea))
            cv2.rectangle(annotated, (x, y), (x + bw, y + bh), (0, 255, 0), 3)
            cv2.putText(annotated, f"GO GREEN ({area_g}px)", (x, max(25, y - 10)),
                        cv2.FONT_HERSHEY_SIMPLEX, 0.75, (0, 255, 0), 2)

        return sig, info, annotated
```

class RobotHardware:
    def __init__(self):

        self.bot = Transbot()
        self.bot._Transbot__uart_state = 0
        self.bot.create_receive_threading()
        time.sleep(0.5)

    def set_arm(self, j7=None, j8=None, j9=None, runtime=600):

                  self.arm[2] if j9 is None else j9]
        with self.lock:
            self.bot.set_uart_servo_angle_array(int(target[0]), int(target[1]), int(target[2]), run_time=int(runtime))

        with self.lock:
            self.bot.set_beep(int(ms))
