# 字
二进制序列
二进制序列的长度叫**字长** （bit）

# 机器字
能直接处理的二进制位数
CPU内部与整数运算相关的寄存器中保存的字

例：1号通用寄存器中保存 0011 1100这个机器字，准备给ALU运算，说这个事一个机器字，长度为8

机器字长反映了计算机能直接处理的二进制数据的位数，决定了计算机的运算精度

# 指令字
一个指令中包含的二进制序列，IR中保存了1100 0011

# 存储字
存储单元里的保存二进制序列宽度
# 机器字长
机器字长是CPU 内部用于整数计算的数据通路宽度，
所以与机器字长相同长度的是CPU内部进行运算，存储 ，传送的部件，
\==ALU 通用寄存器
