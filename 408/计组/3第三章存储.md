# [[3第三章存储]]




# 透明
透明代表不可见
虚拟存储器需要对操作系统实现地址映射
对操作系统的设计者来说（**系统程序员**）是**不透明**的
对**应用程序员**写的程序使用的是虚拟地址，是**透明**的
分段对低级语言程序员是**不透明**的（他们也是系统程序员）

对以下透明
- **编译系统和装配程序（汇编器/链接器）：** 它们在把你的源码编译成可执行文件时，只负责构建一个**连续的、从 0 开始的、一维的“逻辑地址空间”**。在它们眼里，程序是一整条连续的、完美的线性代码流。
    
- **用户程序（CPU执行的指令）：** 运行时，指令里写出的地址也是这个连续的逻辑地址（例如 `0x00401234`）。

对以下不透明：
- 对操作系统/硬件不透明
