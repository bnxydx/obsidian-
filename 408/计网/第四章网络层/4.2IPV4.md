![](Pasted%20image%2020260727104838.png)
1. 4：版本
2. 4：首部长度（知道首部有多少个字节）
	1. 0~15，**以x4B为单位**
3. 8：区分服务
4. 总长度，**1字节为单位**
5. 16：标识.区分分片是从哪个IP数据包来的
6. 3：标志_（次低位DF）（最低位MF）
	1. MF(more frame) = 1表示后面还有分片
	2. MF = 0这是最后一个
	3. DF(devide frame) = 1不允许被分片
	4. DF= 0允许被分片
7. 13：片偏移.在原始数据报的位置（用来恢复数据报）后边需要x8（片偏移 * 8）**以8字节为单位**
	1. 每个分片的数据部分必须是8B的整数倍
8. 8：生存时间：允许通过的最大路由器数量TTL = 6
	1. 每经过一个路由器就减1
9. 8：协议TCP = 6 ，UDP = 17
10. 16：首部校验和：每个路由器只需要校验首部，如果设置为全零，则连首部都不需要校验
11. 32：源地址
12. 32：目的地址

子网划分可以把一个网络拆分为多个网络，通过添加一个子网号来表示代表第几个网络

| 网络号   | 子网号  | 主机号   |
| ----- | ---- | ----- |
| 16bit | 2bit | 14bit |
```
2bit就可以划分为4个子网

```
配完子网后需要设置一个子网掩码
**子网掩码**
子网掩码的前n个1是到包括子网号的全部，剩下的0是主机号的位置

用来看主机是在哪个子网段的

做法：
把IP与子网掩码做&操作，找到<网络号，子网号>

特点：
使用子网掩码的网络和以前的网络是可以相互连通的
对于没有配置子网划分的网络，
C类255.255.255.0
B类255.255.0.0
A类255.0.0.0

### 发送IP数据报的过程
1. 判断是否属于同一网络
	1. 检查本机IP和目的IP的网络前缀是否相同
		1. 相同是同一网络
		2. 不同是不同网络
2. IP数据报封装成MAC帧
	1. 如果属于同一网络，就通过ARP协议找到目的主机的MAC地址，然后把Ip数据包封装成帧，发送给目的主机
	2. 如果不属于同一网络，通过ARP协议找到**默认网关**的MAC地址，

### 路由器转发一个IP数据报
1. 某个接口接收到IP数据报
2. 对IP数据报首部进行校验，并找到目的IP地址
3. 检查转发表
	1. 目的网络号，子网掩码，转发接口
	2. 检查目的IP地址与每个表项是否匹配
4. 转发
	1. 根据匹配的接口转发IP数据报

# ARP地址解析
查询同一网络的<IP地址，MAC地址>
**数据结构**：
ARP表
每个主机和路由器都有自己的ARP表

## 过程

> ARP 解析分为两步：**广播请求 + 单播响应**，通过"问-答"机制完成 IP 到 MAC 的映射。

1. **ARP 请求（广播）**
   - 发起方封装 ARP 请求分组，声明"我的 IP 是 X，MAC 是 Y，我想找 IP 为 Z 的主机"
   - 封装进 MAC 帧，目的 MAC 为**全 1 广播地址** `FF:FF:FF:FF:FF:FF`，源 MAC 为发起方 MAC
   - 以广播方式发送到局域网内所有设备
2. **ARP 响应（单播）**
   - 目标设备收到请求后，确认自己持有 IP 地址 Z，回复"我就是，我的 MAC 是 V"
   - 封装进 MAC 帧，目的 MAC 为**发起方 MAC**，源 MAC 为目标设备 MAC
   - 以单播方式直接回复发起方
1. 双方各自将 `<IP, MAC>` 映射**存入 ARP 表**，后续通信直接查表，无需重复解析

# 网际报文控制协议ICMP（网络层）
需要封装到IP数据报内
IP协议为ICMP服务
**作用**：让及主机或路由器互相报告网络中发生的差错和异常控制


> ICMP 报文分为**差错报告报文**和**询问报文**两大类：前者用于向源主机报告网络传输中的各类异常，后者用于网络诊断和连通性测试。

### 差错报告报文（5种）

- **终点不可达**（类型3）
  - 路由器发现**目的 IP 地址不可到达**时，向源主机报告（路由不可达）
  - 目的主机发现**目的端口号不存在**（无对应进程）时，向源主机报告（端口不可达）
- **时间超过**（类型11）
  - 路由器收到 **TTL=0** 的 IP 数据报时将其丢弃，并向源主机报告（路程太远，跳数耗尽）
  - 目的主机在**规定时间内未收齐所有分片**时，将已收到的分片全部丢弃并报告
- **参数问题**（类型12）—— 当 IP 数据报**首部参数不合法**或**首部校验出错**时，路由器或主机向源主机报告
- **改变路由/重定向**（类型5）—— 路由器告诉源主机："对于该目的网络，请改用另一台路由器转发，路径更短"
- **源点抑制**（类型4，2012 年已废弃）—— 用于通知源主机网络发生拥塞，请求降低发送速率

### 询问报文（2 对，成对出现）

- **回送请求与回答**（Echo Request/Reply，类型 8/0）
  - A 向 B 发送 **Echo Request**："在吗？请回答我！"
  - B 收到后回复 **Echo Reply**："在！"
  - 典型应用：**ping 命令**，用于测试网络连通性
- **时间戳请求与回答**（Timestamp Request/Reply，类型 13/14）
  - A 向 B 发送 **Timestamp Request**，告知自己当前的发送时间
  - B 回复 **Timestamp Reply**，告知收到请求的时间和发出回答的时间
  - 用于估算往返时延（RTT）和时钟同步
