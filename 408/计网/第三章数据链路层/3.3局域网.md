> 局域网：较小物理范围内，通过传输介质互连计算机与外部设备，实现高速、低时延、**广播/多播**通信。

局域网：一个较小的物理范围，把各种计算机和外部设备，通过双绞线，同轴电缆，光纤等介质互连起来
特点
1. 通常为一个单位所拥有，地理范围和站点数量均有限。
2. 所有站点共享较高的总带宽（较高的数据传输速率）。
3. 具有较低的传输时延和较低的误码率。
4. 各站点地位平等，不存在主从关系。
5. 支持单播，广播和多播通信。

局域网使用的协议
CSMA/CD

**分类**
1. 以太网：总线结构
2. 令牌环：环状结构
3. 光纤分布数字接口IEEE：环状

## 以太网MAC地址
固化再ROM中 48为全球唯一地址
48位长：高24表示厂商代码，低24表示厂商分配的序列号
用12个十六进制表示
MAC地址永远不会变

若路由器接入多个网络，则需要配备多个适配器，每个接口有独立的MAC地址

适配器从网络上每收到一个MAC帧，都要用硬件检查目的地址
1. 单播帧（1对1）MAC
2. 广播帧（1对全体）FF
3. 多播帧

## CSMA/CD

准备：网络层取分组 → 封装成帧 → 存入适配器缓存
信道空闲且持续 ≥ 9.6μs（帧间最小间隔）→ 开始发送
1. 先听后发
2. 边听边发
	1. 发的时候发现别人也发
3. 冲突停发
4. 随即重发

### 退避算法（随即重发）
（截断二进制指数**退避算法**）
	- 冲突后不立即重发，随机推迟一段时间再试，避免再次碰撞
	- 以 **争用期 2τ** 为基本退避单位
	- 第 k 次重传：从 [0, 2^k - 1] 中随机取 r，推迟 r × 2τ
	- k = min(重传次数, 10)：前 10 次窗口指数增长，之后恒为 [0, 1023]
	- 思想：冲突越多 → 窗口越大 → 连撞概率越低
	- 连续 16 次全部失败 → 放弃该帧，向高层报错
> 载波监听多点接入/碰撞检测：边发边听，冲突后按**截断二进制指数退避算法**随机重传，连续 16 次失败则放弃。
 
### CSMA/CD争用期
主机最多经过2t的市场可以检测到碰撞
![](./picture/image-20260713125939.png)
1. 2t称为争用期和碰撞窗口
2. 如果超过争用期还没有检测出碰撞，就肯定不会发生碰撞
3. 10Mb/s以太网争用期定位512比特发送时间，即51.2微秒，总线长度不超过5120




**检测出错**
![](./picture/image-20260711154624.png)
最长2τ检测出冲突（争用期/冲突窗口），最短0τ
争用期内无冲突→发送成功；有冲突→中断，帧无效，靠重传恢复

### 最短帧长
> 帧发送时间必须 ≥ 争用期，否则发完才知冲突，发送方误判成功不再重传。

- 问题：短帧发出后未检出冲突 → 接收方收错帧 → 发送方不知情不重传
- 公式：**最短帧长** = 2τ × 数据传输速率
- 10Mbps以太网：51.2μs → 512bit = **64B**
- 冲突必在前64B内，64B内无冲突则信道抢占成功
- 不足64B → 填充补齐

1. 以太网规定最小帧长64字节（512b）
	1. 如果少于需要填充
2. 最小帧长可以确保再帧发送完成之前检测到碰撞
3. 所以只要少于64字节都是无效的帧

## CSMA/CA
- 在传播过程中，信号的强度会逐渐减弱
- 在所有站点内，不一定都可以互相监听，存在（隐蔽站）
从而**无法检测冲突**
![](./picture/image-20260712103256.png)
AB都在AP的覆盖范围内，但是距离远无法互相监听
AB互为隐蔽站
AB同时发数据，冲突均无法察觉

CD冲突检测
CA冲突避免
**特点**
基于停止等待协议
每发完一个数据都要收到确认帧才可以继续发
每次发送数据前必须检测信道，如果信道忙，则禁止发送
如果空闲，也需要等待一段短暂的随时间（**IFS帧时间间隔**）
1. DIFS 最长的IFS
2. PIFS 中等
3. SIFS 最短的时间间隔
![](./picture/image-20260712104104.png)
```
DIFS RTS SIFS CTS SIFS data SIFS ACK DIFS
```
RTS：谁收到RTS就要T(s）不能发数据
CTS：

**网络分配向量NAV（虚拟载波监听）**
- 源站发送数据前，帧首部"持续期"字段写入占用信道总时长
- 其他站点收到后设置NAV，倒计时期间暂停发送
- 效果等同于持续监听信道 → 降低冲突概率

# 以太网交换机
数据数据链路层的设备，全双工
交换机：多端口网桥
特点：
可以根据MAC地址转发帧
可以隔离冲突域
有并行性，同时连接对多端口，可以同时通信
全双工
不能采用多个网络层协议实现网络互连 
 
## 自学习功能
即插即用
核心：交换表
MAC地址和端口号对照表
MAC：48bit，但是在同一局域网下只有最后两位不同，只需要记录最后两位
### 转发过程
1. A->B
2. 没有，然后广播
3. 记录A 1
4. B给A发
5. 记录B 3
6. 如果不在表内，就把当前入的加到表里
7. 检查目的地址，如果找不到就广播，其他所有交换机检查发送的端口是否存在，不存在就加到表里
![461](./picture/image-20260726162227.png)
8. 过期作废：设备每个表项的有效期，过期自动作废
