判断一个协议工作在哪一层：
**封装准则（最通用）：** 协议 X 的报文被哪个层次的报文头部直接包裹，X 就位于该层的**上一层**。

- 被 MAC 帧封装 $\rightarrow$ 网络层（如 IP、ARP）。
    
- 被 IP 数据报封装 $\rightarrow$ 传输层（TCP/UDP）或网络层内部协议（ICMP、IGMP、OSPF）。
    
- 被 TCP/UDP 数据段封装 $\rightarrow$ 应用层（HTTP、DNS、RIP、BGP）。

| **层次**    | **协议全称与缩写**            | **承载 / 下层封装** | **关键标识 / 端口**       | **核心功能与考点特征**                                       | 连接性       |
| --------- | ---------------------- | ------------- | ------------------- | --------------------------------------------------- | --------- |
| **应用层**   | **HTTP / HTTPS**       | TCP           | 80 / 443            | 超文本传输；无状态；Cookie/Session；持久/非持久连接；HTTPS 加密（SSL/TLS） | **连接TCP** |
|           | **DNS**                | UDP / TCP     | 53                  | 域名解析（查询一般用 UDP，区域传输用 TCP）；递归与迭代查询                   | 无连接       |
|           | **FTP**                | TCP           | 21 (控制) / 20 (数据)   | 双连接模式：控制连接在会话期保持，数据连接按需开关；主动/被动模式                   | **连接**    |
|           | **SMTP / POP3 / IMAP** | TCP           | 25 / 110 / 143      | 邮件发送（SMTP）与拉取（POP3/IMAP）；MIME 扩展                    | **连接**    |
|           | **DHCP**               | UDP           | 67 (服务器) / 68 (客户)  | 动态 IP 分配；四步广播过程（Discover, Offer, Request, ACK）      | 无连接       |
|           | **RIP**                | UDP           | 520                 | 距离-向量路由协议；每 30 秒广播/组播整表；慢收敛与路由环路（最大跳数 15）           | 无连接       |
|           | **BGP (BGP-4)**        | TCP           | 179                 | 路径-向量路由协议；AS 之间的路由选择；基于策略，不追求最佳跳数                   | 连接TCP     |
|           | **SNMP**               | UDP           | 161 / 162           | 简单网络管理协议；管理站周期轮询与代理 Trap 报警                         | 无连接       |
|           | **Telnet / SSH**       | TCP           | 23 / 22             | 远程终端登录；Telnet 明文传输，SSH 加密认证                         | **连接**    |
| **传输层**   | **TCP**                | IP            | 协议号 6               | 面向连接、可靠传输、字节流、拥塞控制与滑动窗口流量控制、三次握手/四次挥手               | **连接**    |
|           | **UDP**                | IP            | 协议号 17              | 无连接、尽最大努力交付、面向报文、首部开销小（8 字节）、无拥塞控制                  | 无连接       |
| **网络层**   | **IP (IPv4 / IPv6)**   | MAC 帧         | 类型值 0x0800 / 0x86DD | 核心无连接数据报投递；首部校验和；分片与重组；CIDR 与子网划分                   | 无连接       |
|           | **ARP**                | MAC 帧         | 类型值 0x0806          | IP 地址到 MAC 地址解析；广播请求，单播响应；ARP 欺骗与缓存表                | 无连接       |
|           | **ICMP**               | IP            | 协议号 1               | 网络排错与控制；差错报告报文与询问报文；支撑 Ping (Echo) 和 Traceroute     | 无连接       |
|           | **IGMP**               | IP            | 协议号 2               | 组播成员管理；主机加入/退出多播组；局域网路由器协同维护组播成员关系                  | 无连接       |
|           | **OSPF**               | IP            | 协议号 89              | 链路状态路由协议；Dijkstra (SPF) 算法；洪泛链路状态通告 (LSA)；快速收敛无环路   | 无连接       |
| **数据链路层** | **CSMA/CD**            | 物理层位流         | 协议规范 (IEEE 802.3)   | 有线局域网介质访问控制；先听后发、边发边听、冲突停发、随机重发（二进制退避）              | 无连接       |
|           | **CSMA/CA**            | 物理层信号         | 协议规范 (IEEE 802.11)  | 无线局域网介质访问控制；冲突避免机制；RTS/CTS 预约信道；ACK 帧确认             | **连接**    |
|           | **PPP**                | 物理链路          | 点对点封装               | 面向字节的点对点链路协议；支持差错检测（CRC）但不纠错、不重传；提供 PAP/CHAP 认证     | **面向连接**  |
|           | **HDLC**               | 物理链路          | 点对点封装               | 面向比特的点对点控制；使用位填充（5个连续“1”填“0”）；可靠传输（具有确认重传）          | **面向连接**  |
