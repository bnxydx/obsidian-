# 考研英语二 (2010—2026) 真题核心词智能背诵系统

本系统为纯静态单页 Web 应用（HTML + CSS + JavaScript），无需搭建任何服务器或安装依赖，**直接用浏览器双击 `index.html` 即可使用**。

---

## 🎯 核心功能与使用特点

1. **精细化范围选择**：
   - **年份选择**：涵盖 **2010 ~ 2026** 全真题年份（共 17 年，4385 个核心词汇与短语），亦可单选指定年份。
   - **篇章/题型选择**：支持精准定位到「完形填空」、「传统阅读 Text 1~4」、「新题型」、「翻译与写作」。
   - **词数联动**：选择范围后实时展示词库数量，支持乱序洗牌或真题原始顺序。

2. **主动回忆背诵模式（无选项干扰）**：
   - 只展示大号英文单词/短语与发音按钮，彻底杜绝选择题看选项猜答案的虚假记忆。
   - 第一阶段操作：**【记得 (1 / J)】** 与 **【不记得 (2 / K)】**。
   - 第二阶段操作（查看答案）：
     - 展开详细词性与中文释义，若勾选自动发音会即时标准朗读。
     - 若第一步选了“记得”，看了解释发现其实想错了，可点击 **【记错了 (放回重背)】**；若确定记住则点击 **【确实记住了 (下一个)】**。
   - **循环淘汰机制**：
     - 真正记住的单词立即从本轮中移出，不再出现。
     - 选了“不记得”或“记错了”的单词会自动推入队列末尾，循环复习直到彻底掌握。

3. **每十个一组阶段小结**：
   - 每背满 10 个词，系统自动弹窗汇总当前 10 个词的拼写、词性、中文含义及当前掌握状态（已记住 / 待复习）。
   - 可一键快速浏览并点击朗诵巩固，按 **【Enter / 空格】** 即可直接继续下一组。

4. **全套键盘极速盲打快捷键**：
   - `1` 或 `J`：记得 / 确认记住了
   - `2` 或 `K`：不记得
   - `3` 或 `Backspace`：记错了（回炉重背）
   - `空格 (Space)` 或 `Enter`：翻开答案 / 下一个 / 小结继续
   - `V` 或 `P`：单词标准英语发音

5. **4385 真题核心词全量检索词库**：
   - 点击右上角放大镜图标即可打开完整词库抽屉，支持对 4385 个词汇的英文、中文、题型、年份进行实时搜索。

6. **深浅双色主题支持**：
   - 点击右上角月亮/太阳图标，支持在现代化暗夜黑模式与护眼明亮模式之间自由切换。

---

## 📂 文件结构说明

- `index.html`：网页主入口，双击直接在 Chrome / Edge / Firefox 运行。
- `style.css`：极简现代卡片式响应式样式表。
- `app.js`：完整背诵交互与队列循环逻辑。
- `words_data.js`：2010—2026 全量 4385 核心词汇数据（JavaScript 格式，支持双击本地运行无 CORS 拦截）。
- `words_data.json`：全量核心词汇纯 JSON 数据文件，方便备份与二次开发。
