# 单链表的节点定义
```c
typedef struct LNode{
	int data;
	struct LNode *next;
}LNode,*LinkList

struct LNode *p ==== LinkList p;

```
- 使用LinkList 的原因是：
链表通过第一个节点找到别的节点，所以这个变量就专门来表示第一个节点

完全等价的写法
```
LNode *func(LNode *P)

LinkList func(LinkList L)
```
# 访问
普通的结构体变量
```c
使用点来访问
LNode node;
node.data = 10;
node.next = NULL;
```
结构体指针变量
```c
p : 指针变量
LNode *p = (LNode *)malloc(sizeof(LNode));
p->data = 10;
p->next = NUll;
```

# 临时指针向前走
```c
LNode *p = (LNode*)malloc(sizeof(LNode));
p = p -> next
```
# 修改临时指针
```
p -> next = p ->next -> next
把p指向的下一节点跳过了
```
