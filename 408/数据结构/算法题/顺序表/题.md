# 逆置元素
- 空间复杂度o（1）
- 顺序表

思路：
交换
```
a[i],a[n - i - 1]


```


```c
#include<stdio.h>

int n = 11;
void swap(int *a,int l,int r){
    int tmp = a[l];
    a[l] = a[r];
    a[r] = tmp;
}
int main(){
    int *a = (int*)malloc(sizeof(int)*n);
    for(int i = 0; i < n ;i ++)
        a[i] = i;
    
    for(int i = 0; i * 2 < n;i ++)
        swap(a,i,n - i - 1);
    for(int i = 0 ;i < n; i ++)
        printf("%d ",a[i] - n + i + 1);
        
}
```
