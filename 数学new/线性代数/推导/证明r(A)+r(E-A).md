设 $A$ 为 $n$ 阶方阵，满足 $A^2 = A$（即 $A$ 为幂等矩阵）。可以通过以下两种经典方法进行证明
### 方法一：利用秩的不等式（Sylvester 不等式与子加性）

1. **证明 $\le n$：**
    由题设条件 $A^2 = A$，可得：
    $$A(E - A) = A - A^2 = A - A = O$$
    根据 Sylvester 降阶定理（或矩阵乘积的秩不等式）：
    若 $AB = O$，则 $r(A) + r(B) \le n$。
    将 $B = E - A$ 代入，即得：
$$r(A) + r(E - A) \le n$$
2. **证明 $\ge n$：**
    根据矩阵和的秩的次加性：
$$r(A + B) \le r(A) + r(B)$$
[[证明r(A+B) 小于等于r(A)+r(B)]]
    令 $B = E - A$，则：
$$r(E) = r(A + (E - A)) \le r(A) + r(E - A)$$
    因为 $E$ 为 $n$ 阶单位矩阵，所以 $r(E) = n$，即：
$$n \le r(A) + r(E - A)$$

综合两式，必有：
$$r(A) + r(E - A) = n$$
### 方法二：利用齐次线性方程组的解空间维数（秩-零度定理）

1. 由 $A(E - A) = O$ 可知，$E - A$ 的每一个列向量 $x$ 都满足：
    
      
    
    $$Ax = 0$$
    
    因此，$E - A$ 的列向量构成的向量空间是齐次线性方程组 $Ax = 0$ 的解空间的一个子空间。
    
    由此可知：
    
      
    
    $$r(E - A) \le \dim(N(A))$$
    
    其中 $N(A)$ 为 $Ax = 0$ 的基础解系所张成的解空间。
    
      
    
2. 反之，若向量 $x \in N(A)$，即满足 $Ax = 0$，则：
    
      
    
    $$(E - A)x = x - Ax = x - 0 = x$$
    
    这表明任何满足 $Ax = 0$ 的解向量 $x$ 都可以写成 $(E - A)x$ 的形式，即 $x$ 必然属于 $E - A$ 的列空间（值域）。
    
    由此可知解空间完全包含在 $E - A$ 的列空间中：
    
      
    
    $$\dim(N(A)) \le r(E - A)$$
    
3. 综合上述两点，得：
    
      
    
    $$r(E - A) = \dim(N(A))$$
    
4. 由秩-零度定理（Rank-Nullity Theorem）：
    
      
    
    $$r(A) + \dim(N(A)) = n$$
    
    将 $\dim(N(A)) = r(E - A)$ 代入，即证：
    
    $$r(A) + r(E - A) = n$$
