### 反例 1：可微 $\centernot\implies$ 一阶偏导连续（箭头向上不可逆）

  

  

> **经典函数（振荡类）**：
> 
>   
> 
> $$f(x, y) = \begin{cases} (x^2 + y^2)\sin\left(\dfrac{1}{x^2 + y^2}\right), & (x, y) \ne (0, 0) \\ 0, & (x, y) = (0, 0) \end{cases}$$

- **验证可微**：
    
    在 $(0, 0)$ 处计算偏导数：$f'_x(0, 0) = \lim\limits_{x \to 0} \frac{x^2\sin(1/x^2)}{x} = 0$，同理 $f'_y(0, 0) = 0$。
    
    代入可微充要条件极限式：
    
      
    
    $$\lim_{\rho \to 0} \frac{\vert{}f(x, y) - 0 - (0 + 0)\vert{}}{\rho} = \lim_{\rho \to 0} \frac{\rho^2 \vert{}\sin(1/\rho^2)\vert{}}{\rho} = \lim_{\rho \to 0} \rho \left\vert{}\sin\frac{1}{\rho^2}\right\vert{} = 0$$
    
    极限为 0，所以在 $(0, 0)$ 处**完全可微**。
    
      
    
- **验证偏导数不连续**：
    
    当 $(x, y) \ne (0, 0)$ 时求导：
    
      
    
    $$f'_x(x, y) = 2x\sin\frac{1}{x^2+y^2} - \frac{2x}{x^2+y^2}\cos\frac{1}{x^2+y^2}$$
    
    当 $(x, y) \to (0, 0)$ 时，第二项剧烈振荡，极限不存在，即 $\lim\limits_{(x, y) \to (0, 0)} f'_x(x, y)$ 不存在。
    
    导数极限不存在，故偏导数在 $(0, 0)$ 处**不连续**。
    
      
    

  

  

### 反例 2：偏导存在 $\centernot\implies$ 连续（水平向左不可逆）

  

  

> **经典函数（交叉项分式）**：
> 
>   
> 
> $$f(x, y) = \begin{cases} \dfrac{xy}{x^2 + y^2}, & (x, y) \ne (0, 0) \\ 0, & (x, y) = (0, 0) \end{cases}$$
> 
>   

- **验证偏导存在**：
    
    沿坐标轴 $y = 0$ 时恒有 $f(x, 0) = 0$，故 $f'_x(0, 0) = \lim\limits_{x \to 0}\frac{0 - 0}{x} = 0$；
    
    同理 $f'_y(0, 0) = 0$。偏导数均存在且为 0。
    
      
    
- **验证不连续**：
    
    沿直线 $y = kx$ 趋向原点：
    
      
    
    $$\lim_{\substack{x \to 0 \\ y = kx}} f(x, y) = \frac{k}{1 + k^2}$$
    
    极限值随斜率 $k$ 改变，二元极限不存在，因此在 $(0, 0)$ 处**不连续**。
    
      
    

  

  

### 反例 3：连续 $\centernot\implies$ 偏导存在（水平向右不可逆）

  

  

> **经典函数（棱角/绝对值）**：
> 
>   
> 
> $$f(x, y) = \vert{}x\vert{} + \vert{}y\vert{} \quad \left(\text{或 } f(x, y) = \sqrt{x^2 + y^2}\right)$$
> 
>   

- **验证连续**：
    
    $\lim\limits_{(x, y) \to (0, 0)} (\vert{}x\vert{} + \vert{}y\vert{}) = 0 = f(0, 0)$，在 $(0, 0)$ 处**连续**。
    
      
    
- **验证偏导不存在**：
    
    考察对 $x$ 的偏导数：
    
      
    
    $$f'_x(0, 0) = \lim_{x \to 0} \frac{\vert{}x\vert{} + 0 - 0}{x} = \lim_{x \to 0} \frac{\vert{}x\vert{}}{x}$$
    
    左右极限分别为 $+1$ 和 $-1$，不相等，因此 $f'_x(0, 0)$ **不存在**（同理 $f'_y(0, 0)$ 也不存在）。
    
      
    

  

  

### 反例 4：连续 + 偏导存在 $\centernot\implies$ 可微（斜向上不可逆）

  

  

即便把“连续”和“偏导存在”两个条件合在一起，依然推不出“可微”：

  

> **经典函数（次数不够的分式）**：
> 
>   
> 
> $$f(x, y) = \begin{cases} \dfrac{xy}{\sqrt{x^2 + y^2}}, & (x, y) \ne (0, 0) \\ 0, & (x, y) = (0, 0) \end{cases}$$

- **验证连续**：
    
    利用极坐标或均值不等式：$\vert{}xy\vert{} \le \frac{1}{2}(x^2+y^2)$，可知 $\vert{}f(x, y)\vert{} \le \frac{1}{2}\sqrt{x^2+y^2} \to 0$，极限等于 $f(0, 0)$，函数**连续**。
    
      
    
- **验证偏导存在**：
    
    沿坐标轴函数值恒为 0，容易算得 $f'_x(0, 0) = 0, \; f'_y(0, 0) = 0$，偏导数**均存在**。
    
      
    
- **验证不可微**：
    
    代入可微充要条件判定式（分母多除一个 $\rho = \sqrt{x^2+y^2}$）：
    
      
    
    $$\lim_{(x,y) \to (0,0)} \frac{f(x, y) - 0 - (0 + 0)}{\sqrt{x^2 + y^2}} = \lim_{(x,y) \to (0,0)} \frac{xy}{x^2 + y^2}$$
    
    这正好退化成了反例 2 中的极限，沿 $y = kx$ 趋近时与斜率 $k$ 相关，该极限不存在。
    
    因此在 $(0, 0)$ 处**不可微**。
    
      
    

### 记忆小总结

| **试图推导的错误方向**                         | **致命缺陷在哪里**        | **口诀/代表反例**                         |
| ------------------------------------- | ------------------ | ----------------------------------- |
| **可微 $\centernot\implies$ 偏导连续**      | 导函数本身可能有剧烈震荡       | $(x^2+y^2)\sin\frac{1}{x^2+y^2}$    |
| **偏导存在 $\centernot\implies$ 连续**      | 偏导只管两条坐标轴，管不住斜线撕裂  | $\frac{xy}{x^2+y^2}$                |
| **连续 $\centernot\implies$ 偏导存在**      | 有棱角/尖点，切线斜率不存在     | $\vert{}x\vert{} + \vert{}y\vert{}$ |
| **连续 + 偏导存在 $\centernot\implies$ 可微** | 逼近平面的速度不够快（分子阶数不足） | $\frac{xy}{\sqrt{x^2+y^2}}$         |
