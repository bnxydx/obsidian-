- **多 `[CLS]` 标记插入**：为了获取每个句子的独立表示，BERTSUM 在输入文档的**每一个句子的开头**都插入一个 `[CLS]` 标记，在**每一个句子的结尾**插入一个 `[SEP]` 标记。
    
- **区间段嵌入 (Interval Segment Embeddings)**：标准 BERT 只有针对两个句子的 Segment Embeddings（通常是 0 和 1）。BERTSUM 为了让模型区分多个连续的句子，采用了交替的 Segment Embeddings 策略。例如，文档中有五个句子，它们的 Segment ID 会被交替标记为 `0, 1, 0, 1, 0`（即 $E_A, E_B, E_A, E_B, E_A$）。这有助于模型理解文档的层次和边界。
    
- **句子级分类输出**：经过 BERT 编码后，模型会提取出所有 `[CLS]` 标记对应的隐藏层向量。每一个 `[CLS]` 向量代表其所在句子的语义特征。接着，将这些特征向量输入到一个线性分类层（通常带有一个 Sigmoid 激活函数）中，为每个句子输出一个 0 到 1 之间的分数。分数高于阈值的句子将被“抽取”出来，组合成最终的摘要。
