## 从预训练的BERT提取嵌入
1. 文本向量化
上下文嵌入
### 句子向量化
拿到一个句子，在开头添加`[cls]`结尾添加`[SEP]`
序列长度需要一致，如果不够增加`[PAD]`标记

需要让模型知道`[PAD]`只是填充，需要引入**注意力掩码**
把PAD的位置标记为0，其他地方为1
`attention_mask = [1, 1, 1, 1, 1, 0, 0]`
和
`token_ids = [101, 1045, 2293, 3000, 102, 0, 0]`

---

一起给BETR训练
会得到每个单词的特征

### 句子特征cls
把CLS的特征拿出来，当作句子特征
仅使用[CLS]标记的特征来代表整个句子，并非总是最优选择。
为了获得更全面、更具代表性的句子特征，更好的做法是基于句子中所有标记的嵌入进行**平均或汇聚操作**（如均值池化、最大池化等）。


# 探究 Hugging Face 的Transformers 库，学习使用该库从预训练 BERT模型中提取嵌入
```
库 Transformers == 3.5.1
```
1. 导入模块
```
from transformers import BertModel.BetrTokenizer
import torch
```

2. 下载模型
```
model = BetrModel.from_pretrained('bert-base-uncased')
```

3. 下载并加载用于预训练模型的**词元分析器**（字典）
```
tokenizer = BetrTokenizer.from_pretrained('bert-base-uncased')
```

4. 预处理
```
sentence = "I love Paris"
# 分词并获得标记
tokens = tokenizer.tokenize(sentence)
# 手动添加[cls] [SEP] [PAD]之后
attention_mask = [1 if i != '[PAD]' else 0 for i in tokens]

# 转为标记ID
token_ids = tokenizer.convert_token_to_ids(tokens)
```

5. 获得嵌入向量
model返回的输出是一个有两个值的元组。
第1个值hidden_rep表示隐藏状态的特征，它包括从顶层编码器（编码器12）获得的所有标记的特征。
第2个值cls_head表示[CLS]标记的特征。
```
hidden_rep,cls_head = model(token_ids,attention_mask = attention_mask)

>>>hidden_rep.shape = [1,7,768]
>>>分别代表batch_size = 1，序列长度7，特征向量大小768
>>>cls_head.shape = 1,768
```

## 想从所有层获得嵌入
h1 h2 ...h12
```
from transformers import BetrModel,BertTokenizer
import torch
model = BertModel.from_pretrained('bert-base-uncased',output_hidden_states = True)
# 把这个参数设置为True就可以输出所有隐藏层的特征了
```
![364](Pasted%20image%2020260705223003.png)
**`.unsqueeze(0)`**： 这是最关键的一步。它的作用是在张量的第 0 个位置（也就是最前面）**强行增加一个大小为 1 的新维度**。
`[10] -> [1,10]`
2. 获取嵌入
```
last_hidden_state,pooler_output,hidden_states = model(token_ids,attention_mask=attention_mask)
>>>last_hidden_state.shape = 1,7,768
>>>	last_hidden_state[0][0] cls的特征
>>>	last_hidden_state[0][1] I的特征
>>>pooler_output.shape = 1,768
>>>len(hidden_states) = 13这是一个元组
>>>	hidden_states[0] = h0层活得的所有标记特征
>>>
```
- `hidden_states[0].shape` 的结果是：`(1, 7, 768)`
    
- `hidden_states[6].shape` 的结果是：`(1, 7, 768)`
