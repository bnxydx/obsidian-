
# 二重积分

## 概念与几何意义

> 二重积分是平面区域上的累积求和，几何上表示曲顶柱体的体积。

- 将平面区域 **D** 任意划分为 n 个小区域，每个小区域上函数值 × 面积求和，取 **λ → 0**（小区域直径最大值趋于 0）时的极限
- 几何意义：**D** 是底面投影区域，**z = f(x, y)** 是顶面曲面，积分值 = 曲顶柱体体积
- 定义：$$\iint_{D} f(x,y) \mathrm{d}\sigma = \lim_{d \to 0} \sum_{k=1}^{n} f(\xi_k, \eta_k) \Delta\sigma_k$$

## 性质

- **线性性**：和的积分 = 积分的和；常数因子可提出
- **区域可加性**：D 可拆分为不重叠子区域时，积分 = 各子区域积分之和
- **保序性**：若 f ≤ g 在 D 上恒成立，则 $$\iint_D f(x,y)\mathrm{d}\sigma \le \iint_D g(x,y)\mathrm{d}\sigma$$
- **估值定理**：若 f 在 D 上连续，m、M 为最小和最大值，S 为 D 的面积，则 $$mS \le \iint_D f(x,y)\mathrm{d}\sigma \le MS$$
- **绝对值不等式**：$$\left|\iint_D f(x,y)\mathrm{d}\sigma\right| \le \iint_D |f(x,y)|\mathrm{d}\sigma$$
- **积分中值定理**：若 f 在 D 上连续，则存在 (ξ, η) ∈ D，使 $$\iint_D f(x,y)\mathrm{d}\sigma = f(\xi,\eta)S$$

## 计算

### 直角坐标（X 型 / Y 型）

> 根据积分区域形状选择积分次序，核心是确定上下限。

- **先 y 后 x（X 型）**：做平行于 y 轴的直线穿过区域，与边界至多两个交点 → 确定 y 的上下限（下曲线到上曲线），再对 x 积分
  $$\iint_D f(x,y)\mathrm{d}\sigma = \int_a^b \mathrm{d}x \int_{y_1(x)}^{y_2(x)} f(x,y)\mathrm{d}y$$

- **先 x 后 y（Y 型）**：做平行于 x 轴的直线穿过区域，与边界至多两个交点 → 确定 x 的上下限（左曲线到右曲线），再对 y 积分
  $$\iint_D f(x,y)\mathrm{d}\sigma = \int_c^d \mathrm{d}y \int_{x_1(y)}^{x_2(y)} f(x,y)\mathrm{d}x$$
- **直角三角形区域**：两种次序均可，按方便选择

### 极坐标

> 被积函数含 x² + y² 或积分区域为圆/扇形/圆环时优先使用。

- 变换：**x = r cosθ，y = r sinθ**，面积元素 **dxdy = r dr dθ**
- 适合用极坐标的特征：
  - **被积函数**含 $$f(\sqrt{x^2+y^2}),\ f(\frac{y}{x}),\ f(\frac{x}{y})$$ 形式
  - **积分区域**为圆、圆环、偏心圆、扇形等，如 $$x^2+y^2 \le R^2;\ r^2 \le x^2+y^2 \le R^2;\ x^2+y^2 \le 2ax;\ x^2+y^2 \le 2by$$
- 累次积分：$$\iint_D f(x,y)\mathrm{d}\sigma = \int_\alpha^\beta \mathrm{d}\theta \int_{r_1(\theta)}^{r_2(\theta)} f(r\cos\theta, r\sin\theta)\, r\mathrm{d}r$$

## 对称性与简化

### 奇偶性

> 利用积分区域的对称性 + 被积函数的奇偶性，可大幅简化计算。

- **D 关于 y 轴对称**：看 f 对 **x** 的奇偶性
  $$\iint_D f(x,y)\mathrm{d}\sigma = \begin{cases} 2\iint_{D_{x\ge 0}} f(x,y)\mathrm{d}\sigma, & f(-x,y)=f(x,y)\ \text{(偶)} \\ 0, & f(-x,y)=-f(x,y)\ \text{(奇)} \end{cases}$$
- **D 关于 x 轴对称**：看 f 对 **y** 的奇偶性
  $$\iint_D f(x,y)\mathrm{d}\sigma = \begin{cases} 2\iint_{D_{y\ge 0}} f(x,y)\mathrm{d}\sigma, & f(x,-y)=f(x,y)\ \text{(偶)} \\ 0, & f(x,-y)=-f(x,y)\ \text{(奇)} \end{cases}$$

### 轮换对称性

> 积分区域关于 y = x 对称时，x 与 y 可互换。

- 若 **D 关于 y = x 对称**，则 ∫∫f(x, y) = ∫∫f(y, x)，可直接将 x 替换为 y
- 技巧：先用奇偶性消去奇函数项，再配 合轮换对称性简化

### 被积函数技巧

- 若被积函数**只含 x**（或只含 y），优先选择先对该变量积分，可得到常数因子，简化后续计算
