
# 证明存在一个点 $\xi \in (a,b)$, 使 $F[\xi,f(\xi),f'(\xi)]=0$
f'(x)必须出现

**构造辅助函数用罗尔定理**

构造辅助函数的方法主要有两种，目标都是找到 $g(x)$ 使得 $g'(x) = F[x, f(x), f'(x)]$，从而将 $F[\xi, f(\xi), f'(\xi)] = 0$ 转化为 $g'(\xi) = 0$。

**1. 分析法（还原法）**
根据欲证结论 $F[\xi, f(\xi), f'(\xi)] = 0$ 的形式，逆向分析确定 $g(x)$，使得 $g'(x) = F[x, f(x), f'(x)]$。

常用还原公式：
- $u' \pm v' = (u \pm v)'$
- $u'v + v'u = (uv)'$
- $\frac{u'v - v'u}{v^2} = (\frac{u}{v})'$
- $\frac{f'(x)}{f(x)} = (\ln|f(x)|)'$
1）欲证 $f'(\xi) + \lambda f(\xi) = 0$，令 $F(x) = e^{\lambda x} f(x)$
- 当 $\lambda = 1$ 时（$f'(\xi) + f(\xi) = 0$），令 $F(x) = e^x f(x)$
- 当 $\lambda = -1$ 时（$f'(\xi) - f(\xi) = 0$），令 $F(x) = e^{-x} f(x)$

2）欲证 $\alpha f'(\xi) + \beta f(\xi) = 0$，令 $F(x) = e^{\frac{\beta}{\alpha} x} f(x) \quad (\alpha \neq 0)$

3）欲证 $f'(\xi) + g'(\xi) f(\xi) = 0$，令 $F(x) = e^{g(x)} f(x)$

4）欲证 $f'(\xi) + g(\xi) f(\xi) = 0$，令 $F(x) = e^{\int g(x) dx} f(x)$
（**最一般公式**）



**2. 微分方程法**
1）求微分方程 $F(x, y, y') = 0$ 的通解 $H(x, y) = C$
2）
$$
\text{设辅助函数}g\left( x \right) =H\left( x,f\left( x \right) \right) 
$$

# 证明存在两个点 $\xi,\eta \in (a,b)$，使 $F[\xi,\eta,f(\xi),f(\eta),f'(\xi),f'(\eta)]=0$
后两个必须出现

**方法**：

（1）不要求 $\xi \neq \eta$
在同一区间 $[a,b]$ 上用两次中值定理（拉格朗日、柯西中值定理）

（2）要求 $\xi \neq \eta$
将区间 $[a,b]$ 分为两个子区间，在两个子区间上分别用拉格朗日中值定理
