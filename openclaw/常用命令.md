### 1. 终端交互模式（TUI）的进入与退出
- **进入对话：** 输入 `openclaw tui` 并按回车。屏幕会切换成对话模式。
- **退出对话：** 在对话界面的输入框中，直接按下键盘的 `Ctrl + C`，或者输入 `/exit` 然后回车，即可安全退出对话界面并回到正常的 Linux 命令行提示符。

### 2. 网关后台服务管理命令

网关（Gateway）是 OpenClaw 的大脑。当你关闭终端窗口时，你可能希望它继续运行，或者你需要重启它来加载新配置。

- **启动网关：** `openclaw gateway start` （在后台静默运行）
    
- **停止网关：** `openclaw gateway stop` （彻底关闭 AI 服务）
    
- **重启网关：** `openclaw gateway restart` （修改配置文件或替换模型后必备）
    
- **查看运行日志：** `openclaw logs --follow` （当 AI 报错或失去响应时，用这个命令可以实时查看后台到底发生了什么）
    

### 3. 系统配置与调试命令

这些命令主要用于修改设置或排查连接问题。

- **图形化配置菜单：** `openclaw configure` （最常用，用于切换大模型、配置 API Key 等）
    
- **查询核心密钥：** `openclaw config get gateway.auth.token` （Windows 客户端连接失败要求重配时，用来获取最新 Token）
    
- **系统体检：** `openclaw doctor` （如果系统总是连不上或出错，运行此命令会自动检查环境依赖和网络状态）
    

### 4. 聊天框内的快捷指令（Slash Commands）

无论是使用 Windows 客户端还是终端 TUI，在底部的聊天输入框里都可以使用以 `/` 开头的快捷指令：

- **清除记忆：** `/clear` （清空当前会话的上下文记忆，让它重新开始一个新的话题）
    
- **快速授权：** `/auth openai` （快速唤出配置 API Key 的弹窗，支持所有兼容 OpenAI 格式的模型，如 DeepSeek）
    
- **查看帮助：** `/help` （列出当前界面支持的所有快捷指令）
