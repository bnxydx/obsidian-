# agent-browser 命令总结

> 来源：`新建 文本文档.txt` 终端实操记录（Linux/WSL 环境）

---

## 1. 安装与配置

```bash
# 查看当前 npm 镜像源地址
npm config get registry

# 将 npm 镜像源切换到淘宝镜像（npmmirror），加速国内下载
npm config set registry http://registry.npmmirror.com

# 再次查看镜像源地址，确认已切换成功
npm config get registry

# 全局安装 agent-browser（AI 浏览器自动化 CLI 工具）
npm install -g agent-browser

# 尝试直接运行 agent，检查命令是否可用（结果：command not found，需用完整命令 agent-browser）
agent

# 下载安装 Chrome 浏览器（agent-browser 的运行依赖）
agent-browser install

# 安装 Chrome 并自动安装 Linux 系统依赖库（如 GTK、字体等）
# （本机部分依赖缺失，安装失败）
agent-browser install --with-deps

# 手动安装 Chrome 运行所需的系统依赖库（第一次执行时按了 Ctrl+C 取消）
sudo apt-get install libxcb-shm0 libx11-xcb1 libx11-6 libxcb1 libxext6 libxrandr2 libxcomposite1 libxcursor1 libxdamage1 libxfixes3 libxi6 libgtk-3-0 libpangocairo-1.0-0 libpango-1.0-0 libatk1.0-0 libcairo-gobject2 libcairo2 libgdk-pixbuf2.0-0 libxrender1 libasound2 libfreetype6 libfontconfig1 libdbus-1-3 libnss3 libnspr4 libatk-bridge2.0-0 libdrm2 libxkbcommon0 libatspi2.0-0 libcups2 libxshmfence1 libgbm1 fonts-noto-color-emoji fonts-noto-cjk fonts-freefont-ttf

# 手动安装系统依赖库（第二次执行，确认安装并成功）
sudo apt-get install libxcb-shm0 libx11-xcb1 libx11-6 libxcb1 libxext6 libxrandr2 libxcomposite1 libxcursor1 libxdamage1 libxfixes3 libxi6 libgtk-3-0 libpangocairo-1.0-0 libpango-1.0-0 libatk1.0-0 libcairo-gobject2 libcairo2 libgdk-pixbuf2.0-0 libxrender1 libasound2 libfreetype6 libfontconfig1 libdbus-1-3 libnss3 libnspr4 libatk-bridge2.0-0 libdrm2 libxkbcommon0 libatspi2.0-0 libcups2 libxshmfence1 libgbm1 fonts-noto-color-emoji fonts-noto-cjk fonts-freefont-ttf
```

## 2. 基本使用演示（百度搜索）

```bash
# 打开百度首页
agent-browser open baidu.com

# 获取当前页面的可交互元素快照（Accessibility Tree），每个元素带 ref 编号
agent-browser snapshot -i

# 向 ref=e36（搜索输入框）填入搜索关键词 "AI Agent"
agent-browser fill @e36 "AI Agent"

# 正确点击 ref=e37（百度一下按钮），执行搜索
agent-browser click @e37

# 等待页面网络请求全部完成（页面加载完毕）
agent-browser wait --load networkidle

# 查看搜索结果页的可交互元素快照
agent-browser snapshot -i

# 对当前页面截图并保存为 result.png
agent-browser screenshot result.png

# 关闭浏览器
agent-browser close
```
